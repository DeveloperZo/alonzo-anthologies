# Career profile: GTreasury (Ripple)

Visual cover letter for the Software Engineering Manager role at GTreasury, a Ripple solution. It pairs with the gtreasury resume overlay.

| File | Use |
| --- | --- |
| `career-profile.pdf` | The file to send |
| `career-profile.png` | Preview, or to paste into a message |
| `career-profile.html` | Source. Edit it here, or on the Career Profile 2026 design canvas |

## How it is built

The resume half of this application is the overlay `resumeContent/src/data/tailoring/gtreasury.ts`. Build both PDFs with `npm run apply:package -- gtreasury` from `resumeContent/`. The full workflow is in `_KNOWLEDGE/Documents/Operations/OPER-004-ApplyToAJob.md`.
