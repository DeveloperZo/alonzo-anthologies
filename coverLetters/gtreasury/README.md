## Branch convention

There is one branch per application: `resume/<company>-<role>`, cut from `main`. It holds the resume as it was sent and `coverLetters/<company>/` together.

The four circles follow one meta (see `_KNOWLEDGE/Stories/ST-012/foundation.md`):
- **01:** compounded skills. Stable across companies.
- **02:** the in-demand skill set (AI). Stable across companies.
- **03:** immediate actions. Researched from the job post and limited to what the portfolio proves.
- **04:** the career outcome.

Only 03, 04, and the "For <company>" tag change per company.
