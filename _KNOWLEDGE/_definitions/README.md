# Definitions

Canonical artifact definitions for the Alonzo's Anthologies doc surface. Each file below is the authoring contract for one doc type — required sections, file-name convention, and where it lives.

- [`architecture.md`](./architecture.md) — `ARCH-###`
- [`milestone.md`](./milestone.md) — `M-###` and `RM-###`
- [`operations.md`](./operations.md) — `OPER-###`
- [`roadmap.md`](./roadmap.md) — single canonical roadmap
- [`technical-debt.md`](./technical-debt.md) — `TD-###`
- [`video.md`](./video.md): `VID-###` (short-form and long-form video scripts)
- [`document.md`](./document.md): universal frontmatter that every doc follows
- [`diagram.md`](./diagram.md): `DIA-###` naming, placement, spec sibling and caption

Use these as the contract whenever you create or update a doc.
