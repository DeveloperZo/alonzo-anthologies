Diagrams that explain the system to whoever is building it: architecture
shapes, deploy flows, story dependencies. Each one is an `.svg` plus a `.md`
spec sibling.

Diagrams for published writing do not live here. They sit in a `diagrams/`
folder beside their page under `site/content/`, because Quartz only serves
what is under `content/`. The AI governance series is the existing example.

- Filing contract: [_definitions/diagram.md](../_definitions/diagram.md)
